## [v0.5.00] - 2026-10-11

### Highlights

This is a MAJOR release adding over 300 new components. Documentation URLs now point to dxuireact.com instead of ui.designx.dev, the linting configuration was refined, and the README gained badges and technology stack indicators. Mobile responsiveness across the landing page components was improved, and SPA refresh 404s on Vercel were fixed. Packaging was cleaned up by removing the leading slash from the bin path in package.json, and the footer now displays the NPM package name instead of the version.
