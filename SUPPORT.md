# Getting help

- **Documentation:** start with [dxuireact.com](https://dxuireact.com). Each component page includes usage, props, and a manual install tab.
- **Questions and ideas:** search [existing issues](https://github.com/Sidiora-Labs/DesignX-ui/issues) first, then open a new one with the feature request template.
- **Bugs:** open a [bug report](https://github.com/Sidiora-Labs/DesignX-ui/issues/new/choose) with a minimal reproduction.
- **Security issues:** report privately. See [SECURITY.md](SECURITY.md).

When asking for help, include the component name, your React and Tailwind versions, and the output of the CLI command that failed.
